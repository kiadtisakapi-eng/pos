# Erotica Barber & Massage — POS

ระบบขายหน้าร้าน (POS) สำหรับร้านตัดผม + นวดเพื่อสุขภาพ ทำงานเป็น **PWA** (ติดตั้งลงมือถือ/iPad ได้ ใช้ออฟไลน์ได้) เก็บข้อมูลในเครื่องด้วย IndexedDB และ sync ขึ้น Google Sheets

> 📘 **คู่มือเริ่มใช้งานแบบละเอียด (มีภาพ): เปิดไฟล์ `คู่มือเริ่มใช้งาน.html`**

---

## เริ่มใช้งานเร็ว (Quick Start)

### 1) นำขึ้นเว็บ — ใช้ชุด `deploy.ps1`

1. **แนะนำ: ดับเบิลคลิก `deploy.bat`** (เรียก `deploy.ps1` ให้ และตั้งหน้าต่างให้อ่านชื่อไฟล์ภาษาไทยถูก) — ต้องมี Git for Windows + Node.js และโฟลเดอร์ต้อง clone มาจาก repo นี้
   (ทางสำรอง: เปิด PowerShell ในโฟลเดอร์โปรเจกต์แล้วรัน `powershell -ExecutionPolicy Bypass -File deploy.ps1` — สคริปต์ตั้งรหัสอักษร UTF-8 เองแล้ว)
2. สคริปต์รันชุดทดสอบก่อน ไม่ผ่าน = ไม่ขึ้นเว็บ · ผ่านแล้วเพิ่มเลขแคช `jahn-pos-vN` **เฉพาะเมื่อไฟล์ของแอปเปลี่ยน** (แก้แค่เอกสาร/เทสต์/เครื่องมือ = ไม่เพิ่ม iPad ไม่ขึ้นแถบอัปเดต) และส่งขึ้น GitHub Pages ให้เอง
3. ส่งเฉพาะไฟล์ในรายการ `$safeNewPaths` ของ `deploy.ps1` เท่านั้น · ถ้า `index.html` / `sw.js` / `manifest.json` เรียกไฟล์ที่ไม่อยู่ในรายการ (หรือไม่มีอยู่จริง) สคริปต์ **หยุดก่อน** ไม่ส่งเว็บที่เปิดไม่ขึ้น
4. ก่อน push ตรวจทุก commit ที่จะขึ้น (รวมข้อความ commit และไฟล์รูป) ว่าไม่มี Telegram token / URL หรือรหัส deployment ของ Apps Script · ใต้ `tests/` `tools/` `vendor/` รับเฉพาะไฟล์โค้ด/ฟอนต์/รูป ไฟล์ชนิดอื่นต้องอยู่ในรายชื่ออนุมัติ

> ⚠️ **ห้ามลากทั้งโฟลเดอร์ขึ้นเว็บ หรืออัปโหลดไฟล์เองผ่านหน้าเว็บ** — ในโฟลเดอร์ทำงานมีไฟล์ส่วนตัวที่ไม่ได้ตั้งใจเผยแพร่ ซึ่ง `deploy.ps1` คัดออกให้
>
> ไฟล์ `.nojekyll` มีไว้กันไม่ให้ GitHub ประมวลผลแบบ Jekyll — อย่าลบ

### 2) ติดตั้งบน iPad
เปิดลิงก์ด้วย **Safari** → ปุ่ม **แชร์** → **เพิ่มไปยังหน้าจอโฮม**

### 3) Deploy Backend (Google Apps Script)
1. เปิด Google Sheets ใหม่ → Extensions → Apps Script
2. วางโค้ดจาก `google_apps_script.js` ทั้งหมด → Save
3. เลือกฟังก์ชัน `setupPosApiToken` → กด Run 1 ครั้ง → อนุญาตสิทธิ์ → คัดลอกรหัสที่แสดงใน Execution log
4. เลือกฟังก์ชัน `setupPosOwnerKey` → Run → **จดรหัสเจ้าของร้าน (Owner key)** เก็บไว้กับเจ้าของ — ใช้กู้ข้อมูลจาก Drive / ตั้งเครื่องหลัก / ตรวจกับชีต (ไม่ต้องใส่ไว้ในเครื่อง แอปถามเอง)
5. Deploy → New deployment → **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
6. คัดลอก Web App URL และรหัสจากข้อ 3 → ใส่ในหน้า **ตั้งค่า → Google Sheets** ของแอป
7. แก้โค้ด Apps Script ภายหลัง: Deploy → Manage deployments → ✏️ Edit → **New version** ทุกครั้ง

> แม้ Web App ต้องเปิดเป็น `Anyone` เพื่อให้ iPad เรียกได้ แต่ทุกคำขอจะต้องมีรหัสที่เก็บใน Script Properties จึงไม่อยู่ในไฟล์เว็บหรือ GitHub
>
> ⚠️ **อย่ารัน `rotatePosApiToken` โดยไม่ตั้งใจ** (อยู่ติดกับ `setupPosApiToken`) — มันเปลี่ยนรหัสทันที ทุกเครื่องหลุดการเชื่อมต่อจนกว่าจะวางรหัสใหม่ · อยากดูรหัสที่ถูกต้องให้รัน `setupPosApiToken` (ปลอดภัย แสดงรหัสเดิม)
>
> **เครื่องหลัก:** Apps Script รับสรุปและไฟล์สำรองจากเครื่องแรกที่ส่งขึ้นไป — ตั้งค่าบน iPad ร้านก่อนเครื่องอื่นเสมอ

### 4) ตั้งค่าครั้งแรกในแอป (หน้า "ตั้งค่า")
- เข้าครั้งแรกด้วย PIN เจ้าของเริ่มต้น `123456` → ระบบบังคับตั้ง **PIN ใหม่ 6 หลัก** ทันที
- ใส่ **เลขพร้อมเพย์** (เบอร์ 10 หลัก หรือเลขบัตร 13 หลัก) → QR สแกนจ่ายได้จริง
- วาง **Google Sheets URL** และ **รหัสเชื่อมต่อ Apps Script**
- (ถ้าต้องการ) ใส่ **Telegram Token + Chat ID** สำหรับรายงานปิดกะ

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|------|--------|
| `index.html` | หน้าจอทั้งหมด (SPA) |
| `app.js` | ลอจิกระบบทั้งหมด |
| `style_v2.css` | ดีไซน์ |
| `promptpay-qr.js` | สร้าง QR PromptPay มาตรฐาน EMVCo (สแกนจ่ายจริง) |
| `dexie.min.js` | ไลบรารี IndexedDB |
| `sw.js` | Service Worker (ออฟไลน์) |
| `manifest.json` | PWA manifest |
| `google_apps_script.js` | Backend บน Google Sheets |
| `vendor/` | ไอคอน Font Awesome + ฟอนต์ Sarabun/Outfit ที่เก็บไว้เอง (เดิมโหลดจากเน็ตทุกครั้ง) — **ห้ามลบ ไม่งั้นไอคอนกับตัวหนังสือหายหมด** |
| `tests/` | ชุดทดสอบ — `run-all.js` รันก่อน deploy ทุกครั้ง (ไม่กี่นาที) · `run-all-ui.js` ตรวจหน้าจอ (ต้อง `npm i -D playwright`) |

## ข้อควรรู้
- ข้อมูลเก็บในเครื่อง (per-device). ควรกด **ส่งออกข้อมูล (Export)** สำรองสม่ำเสมอ และตั้ง Google Sheets URL + รหัสเชื่อมต่อให้ข้อมูลขึ้นคลาวด์
- รหัสเชื่อมต่อไม่อยู่ในไฟล์ Export/Backup: เมื่อนำข้อมูลไปกู้บน iPad เครื่องใหม่ ต้องกรอกรหัสนี้ใหม่ในหน้าตั้งค่า
- แก้ไขโค้ด GAS ภายหลังต้อง **สร้าง deployment เวอร์ชันใหม่** ทุกครั้ง
- หลัง deploy ที่ไฟล์ของแอปเปลี่ยน (เลขแคช `jahn-pos-vN` เพิ่ม) เปิดแอปบน iPad ตอนมีเน็ต → แถบ **"🔄 มีเวอร์ชันใหม่ของแอป"** ขึ้น → กด **อัปเดตเลย** (ไม่ต้องปิด-เปิดแอปเอง) · ถ้าไม่ขึ้นภายในราว 10 นาที ปิดแอปแล้วเปิดใหม่ตอนมีเน็ต
